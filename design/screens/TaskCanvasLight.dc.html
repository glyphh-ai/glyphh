Task flow editor

When a custom power is a Task, its Flow tab is the app's React Flow canvas, made editable: add steps, connect them, set each step in the inspector, save. Steps: Trigger, Agent (a slot that hands work to a super power), Model, Connection (a tool on a connected app), Decide, Memory, Skill, Checkpoint, Output. Nothing runs from here; Run now lives on the machine.
