Fit for the role

    What this is, and is not

    • This page runs the same code as the Resume Screener plugin for Claude: it reads the email and the files, checks the timestamps, the files themselves and the writing, and compares the application with the examples held.
    • Ada models decide. The fit, the writing and the comparison start from examples: every example is a generated, fictional application. The timestamp and file models start with nothing, so here a rule answers for them and says so.
    • It has been checked on generated applications and on cases made for the purpose only. It is not proven to tell a real person from a fake one. What was checked.
    • A verdict is a screening, never a judgement of the person. No language model runs on this page.
