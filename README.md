# Glyphh

The official ways in to Glyphh:

- `sdk/typescript`: the TypeScript SDK, a typed client for the Glyphh API
- `sdk/python`: the Python SDK, the same API for Python
- `plugin`: the Glyphh plugin for agent hosts (Claude Code, Claude Desktop, Cursor and others), which connects them to Glyphh over MCP

Both SDKs are generated from the Glyphh API's OpenAPI spec, so they always match the server.
