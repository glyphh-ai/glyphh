# Glyphh mods

Mods for Claude by [Glyphh](https://glyphh.ai). Each one installs on its own.

## Install

```
/plugin marketplace add glyphh-ai/glyphh
/plugin install <mod>@glyphh
```

## The mods

| Mod | What it does |
| --- | --- |
| [drips](plugins/drips) | Visual effects over Claude: confetti, fireworks, hearts, matrix rain; save recipes and let Claude play them |
